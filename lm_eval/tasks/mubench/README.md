# MuBench

### Paper

Title: `MuBench: Assessment of Multilingual Capabilities of Large Language Models Across 61 Languages`

Abstract: [https://arxiv.org/abs/2506.19468](https://arxiv.org/abs/2506.19468)

MuBench is a multilingual benchmark covering 61 languages and 3.9M samples. It translates 12 widely used English benchmarks (ARC-Challenge, ARC-Easy, BMLAMA, GPQA, HellaSwag, MMLU, MMLU-Pro, MultiNLI, SNLI, StoryCloze, TruthfulQA, WinoGrande) with GPT-4o, using back-translation, translation-purity and cultural-sensitivity checks, and keeps test samples aligned across languages.

The paper mainly evaluates base (pre-trained) models, using the cloze template: no task instructions, and each full answer text is scored by log-likelihood, zero-shot, reporting char-length normalized accuracy (accuracy for WinoGrande and BMLAMA). The exceptions are MultiNLI and SNLI, which use the local template in a QA style with 10-shot demonstrations. The local template, with instructions written in each language, is how MuBench supports chat-oriented models.

The tasks here use the `local_template` format: prompt instructions and content are in the target language, and the model picks an answer letter (or an NLI label) by log-likelihood. All tasks are zero-shot except MultiNLI and SNLI, which are 10-shot with demonstrations from the validation split, as in the paper. Because the paper's main results for the other benchmarks use the cloze template, only the MultiNLI and SNLI scores are directly comparable to it.

Homepage: \
[https://huggingface.co/datasets/aialt/MuBench](https://huggingface.co/datasets/aialt/MuBench)


#### Groups

* `mubench_local`: Average over all 61 languages.
* `mubench_local_{lang}`: Average over the 12 benchmarks in one language, matching the paper's per-language score.

#### Tags

* `mubench_local_{benchmark}`: One benchmark in all 61 languages, e.g. `mubench_local_mmlu`.

The configs are generated by `_generate_configs.py`; edit the script rather than the generated files:

```bash
cd lm_eval/tasks/mubench/local
python ../_generate_configs.py --base_yaml_path _mubench_template_yaml \
    --save_prefix_path mubench_local --task_prefix local
```
